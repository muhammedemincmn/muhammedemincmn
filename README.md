## 👋 Merhaba, ben Emin

İlgi alanım **bilgisayar ağları**. Bir paketin bir cihazdan diğerine giderken izlediği yol, ağların birbirini nasıl bulduğu ve bu iletişimin nasıl güvenli tutulduğu ilgimi çekiyor.
